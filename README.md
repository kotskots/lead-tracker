💰 Lead Tracker App

A lightweight web application built with HTML, CSS, and JavaScript, bundled using Vite.
The app focuses on simplicity, fast performance, and a clean UI, with support for modern web features and PWA readiness.

🚀 Features

⚡ Fast development & build setup using Vite

🎨 Clean and minimal UI with custom styling

🧠 JavaScript-driven logic (no frameworks)

📱 PWA-ready (via manifest.json)

🌍 Runs entirely in the browser

🛠️ Tech Stack

HTML5

CSS3

JavaScript (Vanilla)

Vite

PWA Manifest

📂 Project Structure
├── index.html # Main HTML file
├── index.css # Styles
├── index.js # App logic
├── manifest.json # PWA configuration
├── icon.png # App icon
├── vite.config.js # Vite configuration
├── package.json # Project metadata & scripts

▶️ Getting Started
1️⃣ Install dependencies
npm install

2️⃣ Start development server
npm run dev

3️⃣ Build for production
npm run build

📦 Deployment

The production build will be generated in the dist/ folder and can be deployed on:

GitHub Pages

Netlify

Vercel

Any static hosting service
